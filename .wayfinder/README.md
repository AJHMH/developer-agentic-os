# Local Wayfinder Tracker

This repository does not currently have an external issue tracker configured for Wayfinder, so this folder acts as the local markdown tracker.

## Conventions

- `map.md` is the map issue and carries the `wayfinder:map` label.
- Files under `tickets/` are child issues of the map.
- A ticket is unclaimed when `assignee` is empty.
- A ticket is open when `status: open`.
- `blocked_by` lists ticket file paths that must be closed before the ticket enters the frontier.
- In human-facing summaries, refer to tickets by linked title, not bare filenames.
